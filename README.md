## 📖 О проекте

**Revalo 1** — это высокоскоростная автономная веб-витрина (Zero-Dependency Static Showcase), разработанная по строгим канонам дизайн-системы clean-beauty / эко-премиум (на базе эстетики *publicgoods.com*). 

Сайт служит визитной карточкой бренда, объединяя:
1. **Онлайн-продажи на Kaspi.kz** — моментальный переход в прямые карточки товаров с защитой от ухода к конкурентам.
2. **Офлайн-магазин в Алматы** — физическая точка продаж в Тастаке с ценами ниже маркетплейса, а также сервис полиграфии (ксерокопия, сканирование, цветная печать).

---

## ✨ Ключевые возможности

* ⚡ **Zero-Runtime Overhead:** Страница собирается в один легковесный файл `index.html` (~750 KB с полным встроенным каталогом из 1805 товаров). Никаких тяжелых фреймворков и лишних сетевых запросов.
* 🔍 **Умный локальный поиск:** Мгновенный поиск без задержек по заголовкам и категориям с нормализацией текста и встроенным словарем синонимов (*«лего» → «конструктор», «пазлы» → «игрушки», «блокнот» → «тетрадь»*).
* 🏷️ **Категории и фильтрация:** Быстрое переключение категорий с помощью интерактивных чипсов и карусели коллекций.
* 📱 **Боковое Drawer-меню:** Выезжающая адаптивная навигация (`slideInLeft`) со списком разделов, популярными категориями и быстрыми контактами.
* 🎨 **Редакционный сплит-баннер (Editorial Split):** Адаптивный промо-блок для категории детских товаров с пропорциональной подачей студийных фотографий и ключевыми УТП.
* 🛍️ **Прямая интеграция с Kaspi.kz:** Каждая карточка товара снабжена точной ссылкой формата `/shop/p/.../?m=17768037`, привязывающей клиента к магазину Revalo 1.

## 🗂 Структура проекта

```
Revalo/
├── AGENTS.md           # 📜 Неизменяемая дизайн-система и правила верстки
├── build.mjs           # ⚙️ Главный скрипт сборки витрины (генерирует index.html)
├── collect.mjs         # 🛰️ Парсер каталога мерчанта Revalo 1 с Kaspi.kz
├── gapfill.mjs         # 🧩 Добор пропущенных страниц каталога
├── merge.mjs           # 📦 Склейка чанков в единые products.json и products.csv
├── index.html          # 🚀 Готовая собранная витрина для продакшена
└── data/
    ├── products.json   # 🗄️ База данных всех 1805 товаров магазина
    ├── products.csv    # 📊 Экспорт ассортимента в формате CSV
    ├── filters.json    # 🌲 Дерево категорий маркетплейса
    └── chunks/         # 📁 Сырые JSON-чанки собранных страниц
```

## 🛠 Быстрый старт и команды

### 1. Локальный просмотр
Файл `index.html` можно открыть прямо в браузере или запустить через любой локальный сервер:
```bash
# Через Python:
python -m http.server 8080

# Или через Node.js (npx):
npx serve .
```

### 2. Сборка витрины
Для обновления цен на ксерокопию или повторной генерации `index.html` выполните:
```bash
node build.mjs
```

### 3. Обновление каталога с Kaspi.kz
Сбор актуальных остатков и цен из личного кабинета продавца:
```bash
# 1. Сбор страниц товаров (пакетно):
node collect.mjs --from 0 --to 37

# 2. Склейка собранных данных в data/products.json:
node merge.mjs

# 3. Пересборка витрины:
node build.mjs
```

## 🖨️ Офлайн-услуги и точка в Алматы

Витрина также презентует офлайн-пространство:
* **Адрес:** г. Алматы, Тастак 1, дом 6А.
* **Навигация:** [Открыть маршрут в 2GIS](https://2gis.kz/almaty/geo/70000001115555356)
* **Услуги:** Ксерокопия А4 (ч/б и цветная), сканирование документов, печать на глянцевой и самоклеящейся бумаге, широкоформат А3.
* **Редактирование цен услуг:** Цены на печать и ксерокс настраиваются в блоке `XEROX_MAIN` и `XEROX_EXTRA` в файле `build.mjs`.
